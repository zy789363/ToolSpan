## Push 与 github.com:443 偶发断连（已解决）

`git push origin main` 首轮 8 次重试均 21 秒后 `Failed to connect to github.com:443`（与 v0.6.0 release 时记录的同款问题）。
诊断：`ping github.com` 通（92ms 无丢包）；`https://github.com` 443 超时；`https://api.github.com` 200 正常；`gh auth status` / `gh repo view` 走 api.github.com 全通。

**解决方案**：用 gh token 作为 extraheader 重试，第 2 次成功：
```bash
git -c credential.helper= \
    -c http.https://github.com/.extraheader="Authorization: Basic $(printf '%s' "x-access-token:$(gh auth token)" | base64 -w 0)" \
    push origin main
```
push 成功：`ea34d4f..f24ff96 main -> main`，本地与远程已同步（`origin/main..HEAD` 为空）。

经验：github.com:443 偶发抖动时，gh-assisted push 重试机制是可靠的 fallback，不必干等网络恢复。
