## Regressions fixed

- Windows 普通 PATH 未包含 MSVC，旧 preflight 误报缺失；现在用 `vswhere` + Visual Studio Developer PowerShell 只读探测并临时加载编译环境。
- Vite 曾监视 Rust `target/` 并因锁定 DLL 触发 `EBUSY`；dev watcher 现明确忽略生成目录。
- Host raw result 与 Renderer 类型曾不一致；现由严格 Zod raw/unified schema、共享 fixture 与跨层 adapter tests 证明 snapshot/jobs/artifacts/logs 兼容。
- Cargo metadata 曾错误预设 MIT；现以 `license-file` 指向明确的 Owner Gate，不虚构法律许可。
- First Run 的 password/config 跨文件失败路径曾可能留下部分状态；现有回滚测试覆盖旧 hash 恢复与新配置不落盘。
- Rust password command 曾只检查非空；现在 Rust 边界强制最少 12 字符并拒绝超过 bcrypt 72 UTF-8 bytes 的输入。
- lib/bin 名称曾产生 debug PDB collision warning；库目标改名后 Rust 与 Tauri bundle 全量复测通过。
