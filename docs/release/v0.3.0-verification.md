## Regressions fixed

- `PREEXISTING_FAILURE`：Windows junction 删除/恢复时按普通 symlink 重建，触发 `EPERM`；现在 Windows 明确使用 junction 类型，focused 12/12 通过。
- `REGRESSION`：Windows/Node 24 不能以 `shell:false` 直接启动 `npm.cmd`；Goal 脚本改为由 Node 执行已解析 npm CLI。
- `REGRESSION`：version checker 使用非 JavaScript EOF escape；改为标准 EOF 断言并增加 syntax/focused 验证。
- `REGRESSION`：release manifest 曾把合法 `dist/state/` 代码误判为运行时 state；过滤器收窄为顶层运行时数据，Secret/config 禁止规则保持不变。
- `REGRESSION`：Node 与 npm 安装目录分离时 runner 找不到 npm CLI；现在只接受形状匹配且可读的 npm/corepack JS 入口，继续保持 allowlist、restricted environment 与 `shell:false`。
