# 威胁模型

本文面向设计、实现、部署和审计 ToolSpan 的工程师，用于识别信任边界、必需控制及明确不承诺的能力。它描述现有边界与验证要求，不构成额外功能承诺。

## 信任边界

1. ChatGPT/Codex 和任意互联网客户端均不可信。
2. Cloudflare Tunnel 负责终止公网 TLS，并且只向本机回环监听器转发流量。
3. MCP/OAuth 输入、文件名、正则表达式、运行器参数和导入的字节均不可信。
4. 已配置的允许根目录、运行器可执行文件、状态目录和操作这台电脑的所有者可信。

## 必需控制

| 威胁 | 控制与验证方式 |
| --- | --- |
| DNS 重绑定与跨站请求 | 只绑定本机回环地址；对未批准的 `Origin` 返回 HTTP 403。 |
| 路径穿越 | 拒绝工具参数中的绝对路径；所有操作都通过规范化的工作区根目录解析。 |
| 符号链接或 Junction 逃逸 | 内容读取使用 `realpath` 验证目标；移动和删除使用不跟随最终链接的目录项解析，确保只操作链接本身；目录枚举与复制不递归跟随链接。 |
| Windows 路径混淆 | 规范化盘符、分隔符和尾部分隔符，并使用不区分大小写的路径比较；除非明确配置为允许根目录，否则拒绝 UNC 或设备路径。 |
| 命令注入 | 使用 `spawn(executable, args, { shell: false })`；校验运行器和每个参数；不得拼接命令字符串。 |
| 任意 Shell 执行 | `shell` 只接受白名单中的只读命令与子命令；不允许 `cmd`、PowerShell、Bash、重定向、管道或命令替换。 |
| 资源耗尽 | 限制请求体、文件和结果大小，以及运行器并发、超时、输出、正则搜索和作业保留数量；目录复制和可恢复删除最多处理 10000 项、256 MiB。 |
| 删除导致不可恢复的数据损失 | `delete_path` 默认先复制到工作区外的回收区并验证项数和字节数，再移除工作区目录项；只有显式 `permanent=true` 才跳过回收。 |
| 回收记录替换或越权恢复 | `recoveryId` 必须是 UUID，清单同时绑定 `workspaceId`；恢复目标重新通过工作区路径守卫解析且不得覆盖现有路径。 |
| OAuth 授权码窃取或重放 | 使用 PKCE S256、一次性短期授权码、重定向 URI 精确匹配和常量时间密钥比较。 |
| 令牌替换 | 每次受保护请求都校验令牌哈希、过期时间、资源或受众（Audience）、客户端和权限范围（Scope）；不得接受查询字符串中的持有者令牌（Bearer Token）。 |
| 重定向滥用 | DCR 只接受 HTTPS 或 localhost 重定向 URI；授权时必须与客户端注册 URI 精确匹配。 |
| 所有者密码泄露 | 仅在独立文件中存储 bcrypt 哈希；不记录表单正文；限制登录尝试频率；除测试外，授权页面只能通过已配置的 HTTPS 公网源提供。 |
| 制品泄露 | 制品文件保存在允许工作区之外；使用不可猜测的 ID 和经过哈希的限时预览令牌；发布需要独立权限范围（Scope）。 |
| 敏感日志 | 使用字段白名单和脱敏的结构化日志；作业日志属于数据制品，不属于应用日志。 |
| 崩溃导致状态不一致 | 使用 SQLite 事务、原子文件替换、优雅关闭和崩溃后重启；将失去进程的作业标记为 `interrupted`。结构化补丁在预检后执行，并在正常执行错误时回滚，但不承诺跨多个文件的操作系统级原子性。 |

## 明确限制

- `networkPolicy: offline_requested` 不等于强网络隔离。仅使用 Node 启动进程无法阻止子进程联网。强隔离需要 Windows Sandbox/AppContainer、容器或防火墙策略，0.1 版本不承诺该能力。
- 将工作目录设置到工作区并不构成操作系统级文件系统沙箱。运行器参数会拒绝绝对路径和父目录穿越，但可信开发工具与工作区代码（例如包脚本、pytest 插件或构建步骤）仍以服务账号的文件系统权限运行。处理不可信仓库时，请使用专用低权限 Windows 账号或外部沙箱。
- 内置 OAuth 授权服务器只适用于单个所有者，不是通用身份提供商；一致性测试通过前不得将其暴露到公网。
- Cloudflare 和 ChatGPT 账号配置仍由所有者执行。仓库脚本可以验证配置，但不能安全地自主创建或批准这些账号操作。
