# Support

## Start here

1. Follow the troubleshooting decision tree in [README.md](README.md) or [README.zh-CN.md](README.zh-CN.md).
2. Run `npm run doctor -- --config <path>` for installed-runtime facts.
3. Run the focused deterministic check for the affected area.
4. Reduce the problem to synthetic configuration and data before sharing it.

When a public repository is published, use its issue templates for reproducible bugs and scoped feature requests. The repository URL, maintainer contact, paid-support offer, and Sponsor identity are **OWNER GATES** and are intentionally absent. No response-time or support-level promise is made.

Security vulnerabilities must use the private process in [SECURITY.md](SECURITY.md), never a public support issue. Do not share passwords, tokens, owner hashes, configuration contents, private paths, logs containing user data, or external-account identifiers.
