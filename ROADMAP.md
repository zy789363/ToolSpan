# ToolSpan roadmap

This roadmap states direction, not release dates or availability promises.

## Core 0.3

- Stable headless MCP server with the exact 27 Tool Contract.
- Deterministic config, OAuth refresh lifecycle, minimal public health, and packed-release smoke.
- Bilingual operator documentation and open-source/release hygiene, subject to Owner legal and publication gates.

## Desktop 0.4

- Optional local desktop control surface around the independently usable headless Core.
- No MCP Client, Agent Runtime, Gateway, arbitrary Shell, or public admin interface.

## Connection Assistant 0.5

- Owner-controlled connection guidance with safe dry-run, reconciliation, and rollback behavior.
- Real external changes remain confirmation gates; management credentials are not persisted.

## Not planned in this product line

- Chat, model hosting, agent planning, memory, MCP federation, multi-device aggregation, automatic account creation, payment, or domain purchase.

The public repository, release cadence, maintainer identity, Sponsor identity, and commercial commitments are Owner Gates and are not promised by this roadmap.
